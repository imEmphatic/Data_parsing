# Проект по парсингу вакансий с hh.ru

Проект реализован для парсинга данных о вакансиях и работодателях с сайта hh.ru с использованием публичного API. Основная цель — спроектировать и загрузить данные о компаниях и вакансиях в базу данных PostgreSQL.

## Функциональные возможности

- **Получение списка компаний** с указанием количества вакансий у каждой из них.
- **Получение списка вакансий** с указанием компании, названия вакансии, зарплаты и ссылки на вакансию.
- **Расчет средней зарплаты** по всем вакансиям.
- **Поиск вакансий с зарплатой** выше средней по всем вакансиям.
- **Поиск вакансий по ключевым словам** в названии вакансии.

## Особенности реализации

- Реализован автоматический процесс создания базы данных и таблиц.
- Для работы с данными использованы **SQL-запросы** (например, `JOIN`, `AVG`, `LIKE`).
- Разработан **интерфейс взаимодействия с пользователем**, который выводит данные в человекочитаемом виде.

## Структура проекта

1. **Модуль для взаимодействия с API** — для получения данных с hh.ru.
2. **Модуль для работы с базой данных** — для создания и заполнения таблиц в PostgreSQL.
3. **Модуль для взаимодействия с пользователем** — для вывода данных в удобном формате.
